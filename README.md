# 渊梦回响-星光武器调整 / Eternal Starlight Weapon Tweaks

对 [Eternal Starlight（永恒星光 / 渊梦回响）](https://www.curseforge.com/minecraft/mc-mods/eternal-starlight) 的武器属性进行可配置调整。

- modId：`eternal_starlight_weapon_tweaks_1787912374`
- 版本：`1.0.0`
- 环境：**Minecraft 1.20.1–1.21 / Forge 47.4.10+**
- 依赖：`eternal_starlight`（在其后加载）
- 作者：2046820954@qq.com
- License：**All Rights Reserved**

## 说明

- 通过 `WeaponAttributeHandler` 在属性阶段按 `WeaponConfig` 改写星光武器的属性数值。
- 具体可调项与默认值见游戏内生成的配置文件（`WeaponConfig`）。
